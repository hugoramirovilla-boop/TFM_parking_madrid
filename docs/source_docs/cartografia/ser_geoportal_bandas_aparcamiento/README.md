# Geoportal SER - Bandas de Aparcamiento

Fuente: Geoportal Madrid / ArcGIS REST Services  
Servicio: GEOPORTAL/SERVICIO_DE_ESTACIONAMIENTO_REGULADO  
Layer: 4 - Bandas de Aparcamiento  
URL: https://sigma.madrid.es/hosted/rest/services/GEOPORTAL/SERVICIO_DE_ESTACIONAMIENTO_REGULADO/MapServer/4

Uso en el TFM:
- Geometría lineal de bandas/plazas de aparcamiento.
- Validación cartográfica de la oferta SER.
- Comparación de plazas por color frente a ser_calles_plazas.

Regla inicial:
- Colores SER regulados: Azul, Verde, Alta Rotación, Rojo, Naranja.
- Gris se conserva como categoría marcada, pero no entra inicialmente en el conteo principal de plazas SER reguladas.
